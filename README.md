# Quarto + Node

Petit projet de démonstration combinant Node.js pour préparer des données et
Quarto pour générer un rapport HTML.

## Prérequis

- Node.js 18 ou plus récent
- Quarto

## Commandes

```bash
npm run data      # génère les données et le fragment Markdown
npm run render    # génère le site dans _site/
npm run preview   # lance la prévisualisation Quarto
```
